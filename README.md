# Employee Attrition Analytics

Uses workforce data to understand what is associated with employee turnover and where retention could improve. Includes data preparation and quality checks, attrition rates by department / tenure / pay / workload, early-tenure metrics, statistical tests, a Poisson rate-ratio regression, an interactive dashboard and a written summary.

> \*\*The dataset is synthetic.\*\* It is generated by `src/generate\_data.py` and contains no real people. Results demonstrate the method and are not findings about a real company. To use real data, replace `data/employees.csv` (same columns) and re-run the steps below.

## Project layout

```
app.py                  Streamlit dashboard (filters, trend, segments, tenure, drivers)
data/employees.csv      Synthetic employee records (anonymous IDs only)
src/generate\_data.py    Creates the synthetic dataset
src/attrition\_lib.py    Cleaning, derived metrics, rates, tests, regression
src/run\_analysis.py     Runs the analysis and writes tables to outputs/
src/build\_static.py     Builds docs/data.js for the GitHub Pages dashboard
docs/                   Static dashboard (index.html + data.js) served by GitHub Pages
outputs/                Result tables (CSV/JSON)
reports/summary.md      Written summary: findings, caveats, recommended actions
```

## Run locally

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt

python src/generate\_data.py      # optional: data/employees.csv is already included
python src/run\_analysis.py       # writes outputs/
python src/build\_static.py       # refreshes docs/data.js
streamlit run app.py             # opens the interactive dashboard
```

To preview the static page, open `docs/index.html` in a browser (needs internet for the chart library).

## Method in brief

* Attrition rate = exits per 100 person-years; monthly rate = exits / average headcount.
* Tenure bands use episode splitting so people count in a band only while they are in it.
* Early-tenure attrition (90 days / 12 months) uses hires made inside the observation window only.
* Chi-square and Mann-Whitney tests for simple associations; Poisson regression with a person-years offset for adjusted rate ratios.
* Privacy: only an anonymous employee ID is stored.

See `reports/summary.md` for findings and caveats.
